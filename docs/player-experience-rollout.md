# 播放体验修复：第一批

## 已实现

- 全屏时顶部、中央、进度条和底部玻璃面板一起隐藏；单击恢复，播放中约 3 秒隐藏。竖屏保留进度与选集入口。
- 用户主动暂停与初始化、缓冲、自动切集分开处理。自动连播不强制恢复中央控制按钮。
- 上下滑动只在竖屏视频区域开始；跟随拖动，距离超过页面高度 18% 或松手速度超过 500px/s 时切集，否则回弹。第一集、最后一集与锁定集不越界。尊重系统减少动画设置。
- 继续使用一份下一集预加载，手动滑动和自动切集互斥，不额外创建第三个播放器。
- 共用 GlassSheet 贴底、左右无外边距、只裁切顶部圆角，安全区留在内容内。
- 选集按 50 集分组，打开时定位当前集，支持前后分组和锁定集禁用。
- 首页、搜索、片单下拉刷新。首页刷新保留旧内容，分页旧请求失效；搜索保留查询，片单读取前等待本地写入结束。
- 首页仅缓存首屏公开剧目摘要，按来源、内容类型、题材区分。无缓存显示骨架屏；有缓存先显示，再更新。失败保留已有内容并显示重试提示。

## 验证

- Flutter 静态分析通过。
- 全部 42 项测试通过。新增缓存失败回退、刷新与分页竞争、分组定位、锁定集禁选、自动连播清屏、用户暂停、上下滑动跟随/回弹/松手切集等测试。
- Android debug APK 构建成功，雷电模拟器安装并能继续播放。
- iPhone 安全区、Home 指示器与手势手感需要重新签名安装新 IPA 后实机验收。Windows 和模拟器不能替代 iPhone 验证。

## 后续独立阶段

1. 倍速：0.75/1/1.25/1.5/2x，持久化，跨集恢复，验证音画同步。
2. 清晰度：先验证源站 auto/720p/1080p 的真实尺寸；接口和缓存键加入清晰度，再实现保留时间、倍速和播放意图的切换、失败回退以及下一集预加载失效。auto 先表示源站默认，不宣称自适应码率。
3. 弹幕：参考项目存在按 offset_time 同步的真实弹幕接口。先从服务器验证样本的时间戳、所属集和实际可用性，再接入只读、限量、去重、缓存及碰撞规避。失败与无弹幕要区分，不影响视频播放。发弹幕与账户体系不在首版范围。
