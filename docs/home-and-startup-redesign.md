# 首页、我的与真实开屏（2026-10-27）

## 实现

- 首页改为 CustomScrollView 与惰性 SliverGrid；题材分类通过 pinned SliverPersistentHeader 吸顶，保持原有主题和玻璃背景。
- 下滑超过约 0.8 个页面后，当前“发现”导航淡入/位移切换为“回顶部”；回到 140dp 内恢复，迟滞避免临界闪烁。其他 Tab 的入口始终是发现，返回时保持页面位置，再次点击平滑回顶。减少动态效果设置关闭位移/缩短回顶。
- 四项导航：发现、搜索、片单、我的。保留原玻璃外观，选中背景按四项位置重新计算。
- 刷新复用 Flutter 的触发状态机但关闭原生/Material 指示器，以自有玻璃浮层和 ZovvLoader 展示下拉、松开、刷新及收起，两端一致；同一组件合并并发刷新，异常保留内容并收起，横向列表不触发主列表刷新。
- 今日精选改为约 156dp 横向卡片；题材/集数只显示一次，不显示未经确认的热度与季数。优先避开继续观看的内容；无候选则隐藏推荐卡。继续观看改成紧凑横向小卡。
- 我的包含本地完整历史、单条删除/确认清空、真实版本构建号、连播/倍速/清晰度/弹幕偏好、外观和双端缓存管理。片单专注收藏。历史删除不影响收藏或视频缓存，不提供账号体系。
- 关于保留简短介绍、设置入口和重播开屏演示，不增加开源许可页面；源代码许可证与归属文件保留。
- 开屏采用更短品牌入场与光感，不使用假百分比。首页目录请求和本地记录读取并行，缓存内容或网络结果准备好即可放行；上限 2.2 秒后降级进入首页现有内容/骨架与重试。视频缓存服务后台初始化，失败不阻塞首页。重播只覆盖现有 Shell，不重跑数据初始化。

## 验证

本地静态分析通过，69 项 Flutter 回归通过。新增交互验证覆盖导航回顶部、Tab 保留位置、自定义刷新去重及启动等待真实准备。Android 原生首页流程与 iOS 云端流程仍待记录最终结果。

播放器和后台接口本轮不变；Android 与 iOS 使用相同共享页面逻辑和国内 IP HTTPS 配置。未增加 iOS 原生 Liquid Glass 或变更已稳定的媒体缓存协议。
